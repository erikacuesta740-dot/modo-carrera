# Modo Carrera Manager (web)

Simulador de mánager de fútbol para el móvil. Ábrelo en el navegador del móvil y añádelo a la pantalla de inicio
(Safari → Compartir → «Añadir a pantalla de inicio»).

- Las carreras se guardan en el propio dispositivo.
- «Jugar online con un amigo»: conexión directa entre los dos móviles (sin cuentas), compatible con la app de Android.
- Jugadores reales según el conocimiento del asistente hasta mediados de 2026, no verificados; no son datos oficiales de EA SPORTS FC.

Código fuente y desarrollo: repositorio privado del proyecto. PeerJS (MIT) incluido en `js/vendor/`.
